# fetchrest

Fetch color rest values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/fetchrest/

## Install / run

```bash
git clone https://github.com/theworker02/fetchrest.git
cd fetchrest
node src/cli.js
node --test
```
